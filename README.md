# SkillMarket - Платформа для репетиторства

## Описание
SkillMarket - это полнофункциональная веб-платформа, где студенты могут находить репетиторов, а репетиторы могут публиковать свои услуги и находить учеников.

## Основные функции ✨

### Для студентов:
- 🔍 Поиск репетиторов по предметам и имени
- 💰 Бронирование занятий с оплатой
- 💬 Рабочий чат в реальном времени
- ⭐ Отзывы и оценки репетиторов
- 🔔 Подписка на репетиторов для отслеживания новых услуг
- ⭐ Добавление репетиторов в избранное

### Для репетиторов:
- 📝 Публикация услуг с указанием цены и длительности
- 📅 Управление бронированиями (подтверждение/отмена)
- 💰 Прием платежей
- 💬 Общение с учениками через чат
- ⭐ Получение отзывов и рейтинга

### Общие функции:
- 👤 Регистрация с выбором роли (студент/репетитор)
- 🔐 Безопасная аутентификация
- 📊 Личный кабинет для каждой роли
- 🔄 Возможность сменить роль в личном кабинете
- 💳 Система оплаты с сохранением способов оплаты
- 🔔 Система уведомлений

## Технологии 🛠️

- **Backend**: Python, Flask
- **Database**: SQLite (Flask-SQLAlchemy)
- **Real-time Chat**: Flask-SocketIO
- **Frontend**: HTML, CSS, Bootstrap 5, JavaScript
- **Authentication**: Werkzeug (password hashing)

## Структура базы данных 🗄️

Приложение содержит **12 сущностей**:

1. **User** - Пользователи (студенты и репетиторы)
2. **Course** - Курсы/Услуги репетиторов
3. **Booking** - Бронирования занятий
4. **Review** - Отзывы и оценки
5. **Subscription** - Подписки на репетиторов
6. **Message** - Сообщения в чате
7. **PaymentMethod** - Способы оплаты
8. **Transaction** - Финансовые транзакции
9. **Subject** - Предметы для обучения
10. **Schedule** - Расписание репетиторов
11. **Notification** - Уведомления пользователей
12. **Favorite** - Избранное (для студентов)
